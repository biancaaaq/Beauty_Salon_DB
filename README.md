# Beauty Salon Management System

This project is designed to streamline salon operations by efficiently managing customer data, appointments, services, employees, and payments using **SQL** and **PL/SQL**.

---

## 📌 About the Project
This system acts as a comprehensive **database management solution** for beauty salons, allowing owners and staff to handle essential business processes seamlessly. With robust database operations and automation through PL/SQL, it ensures efficient and accurate data management.

---

## ✨ Features
✅ **Customer Management** – Add, update, and delete customer records.

✅ **Appointment Scheduling** – Book, modify, and cancel appointments easily.

✅ **Service Management** – Define available services, pricing, and descriptions.

✅ **Employee Management** – Assign employees to specific services based on their expertise.

✅ **Payment Tracking** – Record and manage customer payments efficiently.

---

## 🛠️ Technologies Used
💾 **SQL** – Database structure, queries, and data manipulation.

⚙️ **PL/SQL** – Stored procedures, triggers, and functions for business logic automation.
